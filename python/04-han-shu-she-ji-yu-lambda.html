函数设计与 lambda

写过几章代码后你大概已经察觉：同一段计算逻辑，常常在好几个地方反复出现。函数就是解决这个问题的——把一段逻辑起个名字封装起来，哪里要用就喊一声名字。代码不再重复，读起来也更清爽

把一段逻辑装进"盒子"里

写过几章代码后你大概已经察觉：同一段计算逻辑，常常在好几个地方反复出现。函数就是解决这个问题的——把一段逻辑起个名字封装起来，哪里要用就喊一声名字。代码不再重复，读起来也更清爽。

用 def 关键字定义函数：

# 定义一个最简单的函数
def brew():
    print("咖啡冲好了，请慢用～")

# 调用它
brew()  # 咖啡冲好了，请慢用～

传参的五种方式

按位置对号入座

调用时实参按先后顺序一一对应到形参上：

def order_total(unit_price, count):
    return unit_price * count

pay = order_total(25, 4)
print(pay)  # 100

用名字指定：关键字参数

按参数名传值，谁先谁后无所谓：

def car_profile(brand, price, color):
    print(f"{color}的{brand}，指导价 {price} 万")

car_profile(price=20, color="红色", brand="劲风")  # 红色的劲风，指导价 20 万

和位置参数混用时：位置参数必须排在关键字参数前面。

car_profile("劲风", price=20, color="红色")   # 正确
# car_profile(brand="劲风", 20, "红色")      # 不行！位置参数不能落在关键字参数后面

提前备好默认值

定义时给参数一个默认值，调用时可以不传：

def serve(kind, size="中杯", ice="少冰"):
    print(f"{size}{kind}，{ice}")

serve("拿铁")           # 中杯拿铁，少冰
serve("美式", "大杯")   # 大杯美式，少冰

注意： 带默认值的参数必须排在没有默认值的参数后面。

# 这样写直接语法报错
# def serve(size="中杯", kind):  # SyntaxError!
#     pass

来者不拒：*args

不确定调用方会塞多少个位置参数时，用 *args 全盘接收：

def exam_total(*scores):
    total = 0
    for s in scores:
        total += s
    return total

print(exam_total(80, 92, 75))      # 247
print(exam_total(66, 71, 88, 90))  # 315
print(exam_total())                # 0

args 的真身： 在函数内部，它就是一个元组。

def peek_args(*scores):
    print(type(scores))  # <class 'tuple'>
    print(scores)        # (80, 92, 75)

peek_args(80, 92, 75)

一切收进字典：**kwargs

不确定会收到哪些关键字参数时，用 **kwargs 接住：

def show_laptop(**specs):
    for part, detail in specs.items():
        print(f"{part}: {detail}")

show_laptop(cpu="M3", ram="16G", disk="512G")
# cpu: M3
# ram: 16G
# disk: 512G

kwargs 的真身： 在函数内部，它就是一个字典。

def peek_kwargs(**specs):
    print(type(specs))  # <class 'dict'>
    print(specs)        # {'cpu': 'M3', 'ram': '16G'}

peek_kwargs(cpu="M3", ram="16G")

完整的参数排列顺序

定义函数时，各类参数必须按下面的次序摆放：

def func(位置参数, 默认参数, *args, **kwargs):
    pass

# 综合示例
def combo(a, b=2, *rest, **opts):
    print(f"a={a}, b={b}")
    print(f"rest={rest}")
    print(f"opts={opts}")

combo(1, 3, 4, 5, x=10, y=20)
# a=1, b=3
# rest=(4, 5)
# opts={'x': 10, 'y': 20}

返回值的三个细节

用 return 把结果递出去

def circle_area(r):
    return 3.14 * r ** 2

area = circle_area(3)
print(area)  # 28.26

一次返回多个值

Python 函数可以同时交出多个结果，本质上是打包成了一个元组：

def hi_lo(temps):
    return min(temps), max(temps)

low, high = hi_lo([18, 27, 33, 21])
print(low)   # 18
print(high)  # 33

# 只用一个变量接，接到的是整个元组
both = hi_lo([18, 27, 33])
print(both)        # (18, 33)
print(type(both))  # <class 'tuple'>

不写 return，返回的是 None

def beep():
    print("滴——")

noise = beep()  # 滴——
print(noise)    # None

给函数挂一块说明书（Docstring）

函数体开头放一个三引号字符串，就是它的说明文档：

def delivery_fee(distance, weight):
    """
    估算快递运费。

    参数:
        distance: 配送距离，单位公里
        weight: 包裹重量，单位千克

    返回:
        预计运费（元）
    """
    return 8 + distance * 0.5 + weight * 1.2

# 查看文档
print(delivery_fee.__doc__)

lambda：随手写一个"一次性"函数

lambda 表达式用来创建匿名函数——没有名字、写完就用、用完就扔。当某个逻辑特别简单、又只在一个地方用到时，它能省下不少笔墨。

语法长这样

lambda 参数1, 参数2, ... : 表达式

# 常规写法
def add_tax(price):
    return price * 1.13

# 等价的 lambda 写法
add_tax_l = lambda price: price * 1.13

print(add_tax(200))    # 226.0
print(add_tax_l(200))  # 226.0

三条规矩：

  • 冒号右边只能是一个表达式，写不了多条语句
  • 表达式的计算结果自动作为返回值，不用写 return
  • 一般不给它起名字，现场定义现场用

lambda 还是 def？一张表看懂

对比项 lambda 普通函数（def）
名字 匿名，通常不命名 必须有函数名
函数体 仅限一个表达式 可以写任意多条语句
返回值 表达式结果自动返回 需要显式写 return
适合场景 简单、一次性 复杂、要反复调用

选择原则： 一句话能说清、用完就扔 → 用 lambda；步骤多、或者多处要复用 → 老老实实 def。

高阶函数：把函数当参数传来传去

能接收函数作为参数的函数，叫高阶函数——这正是 lambda 大显身手的舞台。

map() —— 批量加工

对可迭代对象里的每个元素套用同一个操作，返回一个迭代器：

prices = [30, 45, 128, 66]

# 先定义再传入，可行但啰嗦
def half(p):
    return p / 2

result = map(half, prices)
print(list(result))  # [15.0, 22.5, 64.0, 33.0]

# 配合 lambda，一行到位
result = map(lambda p: p / 2, prices)
print(list(result))  # [15.0, 22.5, 64.0, 33.0]

map() 的语义： 给每个元素做一次"转换"。

# 歌名列表 → 歌名长度列表
songs = ["稻香", "晴天", "七里香"]
lens = map(lambda s: len(s), songs)
print(list(lens))  # [2, 2, 3]

# 两列成绩逐位相加
chinese = [86, 92, 78]
math = [90, 85, 88]
totals = map(lambda c, m: c + m, chinese, math)
print(list(totals))  # [176, 177, 166]

filter() —— 按条件筛

只留下让条件成立的那些元素：

scores = [59, 61, 88, 45, 73, 100]

# 留下及格的
passed = filter(lambda s: s >= 60, scores)
print(list(passed))  # [61, 88, 73, 100]

# 留下长度超过 2 的单词
words = ["ok", "filter", "go", "lambda"]
long_ones = filter(lambda w: len(w) > 2, words)
print(list(long_ones))  # ['filter', 'lambda']

filter() 的语义： 给元素做一次"体检"，达标的留下。

# 留下正数
changes = [-3, 5, -1, 0, 2]
ups = filter(lambda x: x > 0, changes)
print(list(ups))  # [5, 2]

sorted() 的 key —— 自定义排序依据

sorted() 和列表的 .sort() 都接受 key 参数，用来回答"按什么排"：

cities = ["Chengdu", "Beijing", "Shanghai", "Xiamen"]

# 按长度排（短的在前）
by_len = sorted(cities, key=lambda s: len(s))
print(by_len)  # ['Xiamen', 'Chengdu', 'Beijing', 'Shanghai']

# 按末尾字母排
by_tail = sorted(cities, key=lambda s: s[-1])
print(by_tail)  # ['Beijing', 'Shanghai', 'Xiamen', 'Chengdu']

# 按长度降序
by_len_desc = sorted(cities, key=lambda s: len(s), reverse=True)
print(by_len_desc)  # ['Shanghai', 'Chengdu', 'Beijing', 'Xiamen']

# 按绝对值排，不看正负
swings = [-120, 85, -60, 210, -15]
by_abs = sorted(swings, key=lambda x: abs(x))
print(by_abs)  # [-15, -60, 85, -120, 210]

max() / min() 的 key —— 按规则找冠军

cities = ["Chengdu", "Beijing", "Shanghai", "Xiamen"]

# 最长的城市名
print(max(cities, key=lambda s: len(s)))  # Shanghai

# 最短的城市名
print(min(cities, key=lambda s: len(s)))  # Xiamen

players = [
    {"nick": "阿风", "kills": 12},
    {"nick": "小雨", "kills": 9},
    {"nick": "大山", "kills": 15},
]

# 击杀数最高的选手
mvp = max(players, key=lambda p: p["kills"])
print(mvp)  # {'nick': '大山', 'kills': 15}

reduce() —— 一路折叠成一个值

reduce() 藏在 functools 模块里，作用是把序列反复"两两合并"，最终压成一个值：

from functools import reduce

fees = [12, 35, 8, 60]

# 累加求和
total = reduce(lambda a, b: a + b, fees)
print(total)  # 115

# 连乘
product = reduce(lambda a, b: a * b, [1, 2, 3, 4, 5])
print(product)  # 120

# 手工版求最大值
peak = reduce(lambda a, b: a if a > b else b, fees)
print(peak)  # 60
