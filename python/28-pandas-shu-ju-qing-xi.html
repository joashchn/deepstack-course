Pandas 数据清洗

上一章把 data/staff.csv 读成了 DataFrame，也留了一串悬念：dtype 清一色 object、员工号 E029 出现两次、月薪一列里同时住着 42k、20w/年、12k~15k 这些互不相识的写法。这些毛病统称「脏数据」——它不是练习题里的故意刁难，而是真实世界的常态：各部门各填各的表、导出工具五花八门、人工录入随手一敲。业内流传一个说法，清洗要吃掉分析师 60% 以上的时间；学完本章你会信。

本章的目标只有一句话：把 staff 花名册洗到「每个字段类型正确、写法统一、缺失有交代」，最后还能拿干净数据回答几个业务问题。所有代码从课程根目录运行，先导入三件套：

import re

import numpy as np
import pandas as pd

staff = pd.read_csv('data/staff.csv')

1. 动手之前，先学会「精准打击」：loc 与 iloc

清洗过程里你会不断需要「只看某几行某几列」「只改符合条件的格子」，这靠两个定位器：

  • loc：按标签定位，df.loc[行标签, 列标签]——行号、列名、布尔条件都算标签；
  • iloc：按位置定位，df.iloc[行位置, 列位置]——纯整数序号，从 0 数起。
staff.loc[0:3, '姓名']     # 第 0~3 行的姓名（loc 切片含右端点）
staff.iloc[0:3, 0:2]      # 前 3 行、前 2 列（iloc 切片不含右端点）
staff.iloc[0, 0]          # 左上角第一个值 → 'E001'

# staff.loc[0:3, '姓名']
0    陈明远
1    林晓彤
2    赵启航
3    孙一诺
Name: 姓名, dtype: object

# staff.iloc[0:3, 0:2]
   员工号    姓名
0   E001  陈明远
1   E002  林晓彤
2   E003  赵启航

loc 更常见的打开方式是布尔筛选——把一个条件表达式塞进中括号：

# 部门是「技术部」的所有行、所有列
staff.loc[staff['部门'] == '技术部']

# 月薪里带 w 的（年薪写法），只看姓名和月薪两列
staff.loc[staff['月薪'].str.contains('w', na=False), ['姓名', '月薪']]
loc iloc
定位依据 标签（行号、列名、布尔条件） 整数位置
切片右端点 包含 不包含
典型场景 按条件筛选、按列名取数 按位置批量截取

两者最容易踩的坑就是切片端点：loc[0:3] 取 4 行，iloc[0:3] 取 3 行。记住口诀「loc 是闭区间，iloc 照抄 Python 习惯」。

2. 数据体检：先看清楚，再动手

体检报告汇总，接下来对症下药：

  1. 重复：E029 整行重复登记；
  2. 类型：工作年限、月薪是 object（字符串），没法计算；
  3. 混入：工作年限里混着「26届」「25届」「应届」——那是毕业届别，不是工龄；
  4. 分类不统一：部门 14 种写法、职级有 p6/P6级、绩效混着字母制和 3.75 数字制，还有「待定」；
  5. 缺失：姓名、部门、月薪、绩效各缺 1~2 个。

3. 重复行：先删为敬

重复数据会让人数翻倍、均值失真，越早处理越好。duplicated() 返回布尔 Series（默认把第二次及以后出现的标 True），配合布尔筛选就能查看；直接删则用 drop_duplicates()：

staff = staff.drop_duplicates()
len(staff)   # 37 → 36

duplicated(keep=...) 与 drop_duplicates(keep=...) 共享同一个参数：'first'（默认）保留第一次出现、'last' 保留最后一次、False 全部标记/全部删除。判断「重复」是看整行所有列；也可以传 subset=['员工号'] 只按工号判重——业务上工号唯一，按它判重更稳。

4. 把「届别」从工作年限里拆出来

工作年限列里混着的 26届、25届、应届，本质是毕业年份信息，被填表人顺手塞错了列。正确姿势是把它拆成独立的一列，而不是简单删掉——信息本身没有错，只是放错了抽屉。

先用 str.contains 圈出这些行（astype(str) 防止有非字符串值，na=False 让缺失值不炸）：

mask = staff['工作年限'].astype(str).str.contains('届', na=False)
staff.loc[mask, ['员工号', '工作年限']]

    员工号 工作年限
13   E014     26届
18   E019     25届
27   E028     应届
36   E036     26届

再用 str.extract() 按正则把数字抠出来（括号是捕获组，\d+ 表示一串数字）：

staff.loc[mask, '工作年限'].str.extract(r'(\d+)\s*届')

      0
13   26
18   25
27  NaN

注意「应届」提不出数字，得到 NaN——它只能告诉我们「还没毕业」，年份只能空着。接着三步落库：建新列、写入年份、把原列的届别值清为 0 年：

years = staff.loc[mask, '工作年限'].str.extract(r'(\d+)\s*届')[0]

staff['毕业年份'] = np.nan                       # 先整列置空
staff.loc[mask, '毕业年份'] = 2000 + years.dropna().astype(int)   # 26 → 2026
staff.loc[mask, '工作年限'] = 0.0                # 届别提走后，工龄按 0 记

这里用 2000 + 年份后两位 是因为填表人习惯写缩写。真实数据里遇到「25 届 vs 2025 届」混写也很常见，思路相同：先统一格式，再转换类型。

draft = {

staff.loc[~staff['部门'].str.strip().isin(draft), '部门'].unique()

写法五花八门，得给每类定一条翻译规则：

原始写法 处理规则 结果
8年、2.5年 提取数字 8.0、2.5
8个月、6个月 数字除以 12 0.7、0.5
10+年、15年+ 取下限 10.0、15.0
<1年、<3年 取中间值（减 0.5，不为负） 0.5、2.5
- 无法解析 NaN
数值（届别行上一步已置 0.0） 直通 0.0

这种「一值一议」的活，正则 + 自定义函数 + apply() 是标准解法（第 4 章练的函数设计，在这里正式上岗——apply 会把列里每个值依次喂给你的函数，再把返回值拼成新列）：

def to_years(val: object) -> float:
    """把各种工作年限写法统一成「年」的浮点数"""
    if pd.isna(val):
        return np.nan
    if isinstance(val, (int, float)):        # 已经是数值（如 0.0），直通
        return float(val)
    s = str(val).strip()
    if s in ('', '-'):                          # 无信息
        return np.nan
    m = re.search(r'(\d+(?:\.\d+)?)\s*(?:\+\s*年|年\s*\+)', s)   # 10+年 / 15年+
    if m:
        return float(m.group(1))
    m = re.search(r'<\s*(\d+(?:\.\d+)?)\s*年', s)                 # <3年
    if m:
        return max(float(m.group(1)) - 0.5, 0.0)
    years = re.findall(r'(\d+(?:\.\d+)?)\s*年', s)                # N年
    if years:
        return sum(float(y) for y in years)
    months = re.findall(r'(\d+(?:\.\d+)?)\s*个月', s)              # N个月
    if months:
        return round(sum(float(x) for x in months) / 12, 1)
    return np.nan


staff['工作年限'] = staff['工作年限'].apply(to_years)

月薪是全表最「脏」的列，先把特殊写法的行请出来亮相：

逐条立规矩（目标单位统一为千元/月）：

写法 含义 规则
42k 千元月薪 直接取数
20w/年 年薪 20 万 × 10 ÷ 12 换算月薪

40k+ 下限写法 取下限 40
16k（含补贴） 带备注 摘掉括号再取数
25k->22k->18k 调薪历史 取最新一档 18
实习、面议、空 无数值 NaN

规则多了，函数就长，但骨架和上一节完全一样——从特殊到一般逐层剥离：

def to_monthly_k(val: object) -> float:
    """把各种月薪写法统一成「千元/月」的浮点数"""
    if pd.isna(val):
        return np.nan
    s = str(val).strip()
    if s in ('', '-', '面议', '实习'):
        return np.nan
    if '->' in s:                                     # 调薪记录：取最新一档
        s = s.split('->')[-1].strip()
    s = re.sub(r'[（(][^)）]*[)）]', '', s).strip()    # 摘掉括号备注
    m = re.search(r'(\d+(?:\.\d+)?)\s*w', s, re.IGNORECASE)      # 年薪 w
    if m:
        return round(float(m.group(1)) * 10 / 12, 1)
    m = re.search(r'(\d+(?:\.\d+)?)\s*k\s*[*x×]\s*\d+', s, re.IGNORECASE)  # 13k*15
    if m:
        return float(m.group(1))
    m = re.search(r'(\d+(?:\.\d+)?)\s*k\s*[~～至]\s*(\d+(?:\.\d+)?)\s*k', s)  # 12k~15k
    if m:
        return round((float(m.group(1)) + float(m.group(2))) / 2, 1)
    m = re.search(r'(\d+(?:\.\d+)?)\s*k\s*\+', s, re.IGNORECASE)  # 40k+
    if m:
        return float(m.group(1))
    m = re.search(r'(\d+(?:\.\d+)?)\s*k', s, re.IGNORECASE)       # 42k
    if m:
        return float(m.group(1))
    return np.nan


staff['月薪'] = staff['月薪'].apply(to_monthly_k)

策略二：删行 dropna()——关键列缺失、行失去意义时用。 部门缺失的那一行，既没法分组统计也没法归属成本，留着只会污染结果：

subset 限定「只看这几列」，只要指定列非空行就保留——没有它，月薪、毕业年份的 NaN 会连累大片无辜的行。

策略三：保留 NaN——信息不足时，诚实比好看重要。 实习生的 实习、待议的 面议 转成的月薪 NaN，硬填（比如填中位数）反而制造假数据。Pandas 的统计函数（mean、describe、groupby）默认自动跳过 NaN，保留它们不影响计算。真要填也有现成写法，但要先问自己一句「业务上说得通吗」：

# 写法示例：本表不采用——给实习生填全员中位数月薪，纯属编数据

毕业年份那 33 个 NaN 同理：老员工们的毕业年份本就无从得知，空着就是最准确的答案。

9. 收尾：改名、排序、类型与终检

数据洗干净了，做点「门面整理」，让表自己会说话：

# 单位写进列名，读者不用猜
staff = staff.rename(columns={'月薪': '月薪(k)', '工作年限': '工作年限(年)'})

# 调整列顺序：关键身份信息在前
staff = staff[['员工号', '姓名', '部门', '职级', '工作年限(年)', '月薪(k)', '绩效', '毕业年份']]

# 可空整数类型：既能存整数，又能存 <NA>（普通 int64 做不到）
staff['毕业年份'] = staff['毕业年份'].astype('Int32')

Int32（大写 I 开头）是 Pandas 的可空整数类型——普通 int32 不允许空值，遇到 NaN 会强制变 float，2026.0 这种尾巴就是那么来的。大写版本让年份显示成整数，缺失显示成 <NA>，两全其美。

10. 洗完的数据要能用：分组聚合

数据洗干净不是终点，能回答业务问题才算功德圆满。这类问题的标准句式是「按 X 分组，看 Y 的统计量」，在 Pandas 里就是 groupby：

dept_stats = (
    staff.groupby('部门', observed=True)['月薪(k)']   # 按部门分组，取月薪列
    .agg(['count', 'mean', 'max'])                    # 人数、均值、最大值一把出
    .round(1)
)

11. 导出：给干净数据一个家

清洗成果要及时落盘，别让下一次分析从头再洗一遍：

# CSV：encoding='utf-8-sig' 带 BOM，Excel 双击打开中文不乱码
staff.to_csv('data/staff_clean.csv', index=False, encoding='utf-8-sig')

# Excel：给不写代码的同事
staff.to_excel('data/staff_clean.xlsx', index=False)

index=False 的意思是不把行索引写进文件——默认编号没有信息量，写进去反而多出一列无名列。（上一章 set_index 过的表另说，那时索引是有业务含义的。）

12. 小结

回顾这次完整的数据清洗，流程可以固化成一张清单，换任何数据集都适用：

  1. 体检：info() + isna().sum() + value_counts()，先看清楚再动手；
  2. 去重：duplicated() 查、drop_duplicates() 删，越早越好；
  3. 拆混入：str.contains 圈出异类，str.extract 提取成新列；
  4. 标准化分类：str.strip / str.upper 清理外观，map() 按字典归一，astype('category') 收尾；
  5. 数值化：写不清规则的用 str 方法，写得出规则的用 apply + 正则；
  6. 处置缺失：能填的 fillna，该删的 dropna(subset=...)，说不通的保留 NaN；
  7. 验证与导出：rename / 列排序 / 可空类型做门面，info() 终检，to_csv / to_excel 落盘。

本章用到的高频 API 速查：

API 一句话
loc / iloc 按标签 / 按位置定位，布尔筛选
isna() / fillna() / dropna() 缺失值的查、填、删
duplicated() / drop_duplicates() 重复行的查与删
str.strip / str.upper / str.contains / str.extract 列级字符串处理
map() 按字典或函数逐值映射，未命中得 NaN
apply() 自定义函数逐值转换（或逐行/列处理）
astype() 类型转换，category、Int32 各有妙用
groupby().agg() 分组聚合，统计量的流水线

数据清洗没有标准答案，只有「业务上说得通」的判断——同一个月薪缺失，做薪酬报告时要删，做人员盘点时可以留。工具给你三把刀，用哪把、怎么用，永远是你的决定。
