模块 03 · 框架上手

LangChain 指南

把原理落成代码：提示词模板、LCEL、流式并发、RAG 三部曲、对话记忆、工具调用与调试。

12 章LangChain

这是一套 LangChain 的 Python 用法课程。不带你搭大工程，而是把 LangChain 的每个核心部件拆开讲清楚：它是什么、怎么装、最小示例怎么写、生产上常栽哪些坑。学完你能把模型、提示词、链、RAG、Agent 这些积木随心组合到自己的项目里。

课程结构

章 主题 一句话
01 认识 LangChain 是什么、生态对比、ChatOllama/init_chat_model、缓存
02 提示词模板与消息 ChatPromptTemplate、多角色消息、MessagesPlaceholder
03 LCEL 与 Runnable 管道 \|、RunnableLambda/Passthrough/Parallel、条件路由
04 流式与并发 stream/batch、asyncio 超时、with_fallbacks/with_retry
05 输出解析器 StrOutputParser、with_structured_output、JSON/列表/正则解析
06 文档加载与切割 TextLoader/PyPDFLoader、RecursiveCharacterTextSplitter
07 嵌入与向量库 OllamaEmbeddings、InMemoryVectorStore、并发控制
08 检索与 RAG 检索参数、MMR、RAG 链组装、来源溯源
09 对话记忆 messages 手动管理、trim_messages、摘要压缩、JSON 持久化
10 工具调用 @tool、bind_tools、tool_calls 解析、手动执行循环
11 Agent create_agent、决策路径观察、工具设计三细节
12 回调与调试 BaseCallbackHandler、astream_events、调试三件套（收官）

主线是「先会用一个模型，再串成链，再喂知识库，再长出手脚」：01-05 讲清模型调用和链式组合；06-08 是 RAG 三部曲（加载切割→嵌入入库→检索问答）；09-11 给应用加上记忆和行动力；12 收官教你观察和调试这一切。

环境准备

# 需要 Python 3.10+、uv、以及本地跑着的 Ollama
ollama pull qwen3:4b          # 对话模型（各章 demo 的默认模型）
ollama pull nomic-embed-text  # 嵌入模型（07/08 章需要）

# 每章 demo 依赖（在课程根目录或各章目录初始化均可）
uv init
uv add langchain langchain-ollama langchain-community pypdf
# 05 章部分解析器在 langchain-classic：
uv add langchain-classic

demo 文件头部注释写明了各自的运行方式。离线也能跑：大部分 demo 检测不到 Ollama 时会自动降级（走固定假响应演示链路逻辑），装好模型后无需改代码即可切回真实调用。

三条学习路线

快速上手（会 Python，想半天入门）：01 → 02 → 03，然后按需跳读。

做知识库（目标是 RAG 问答）：01 → 03 顺读，然后 06 → 07 → 08 三部曲，05 章的 with_structured_output 值得单独看一眼。

做助手类应用（要对话和行动力）：01 → 10 → 11 主线，09 章给多轮对话上记忆，04/12 章上线前补可靠性和调试手段。

demo 的约定

  • 每章 demo/ 下独立 .py 文件，单文件自足，不依赖其他章
  • 离线降级是刻意设计：演示链路逻辑不依赖网络，有 Ollama 时自动切真实模型
  • 示例场景统一是「拾光书屋」阅读社区（藏书/书评/会员），边学边攒一个小应用的直觉

准备好了就从 01 · 认识 LangChain 开始。
