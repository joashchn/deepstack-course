Python 与数据实践

Python 语言核心 + 数据处理工具链：从环境搭建到并发模型，再到 NumPy / Pandas / 可视化。

31 章Python & Data

这是一套写给 AI 时代开发者的 Python 实践课程：默认你有一定编程经验（任何语言），不需要 Python 基础。课程覆盖两件事——把 Python 语言本身学透（从语法到并发），以及掌握 AI 开发绕不开的数据处理工具链（NumPy / Pandas / 可视化）。

课程解决什么问题

写 AI 应用、做 Agent、跑数据 pipeline，Python 是事实标准。但很多人对 Python 的掌握停留在"能跑就行"：

  • 装饰器会写，但描述符、元类只听过名字
  • 知道有 GIL，说不清线程和进程到底怎么选
  • async/await 抄得出样板，事件循环的运转机制是黑盒
  • 拿到一份数据，除了 for 循环不知道还能怎么办

这套课程的立场：语言核心讲深，数据处理讲实用。前 24 章把 Python 的对象模型、并发模型、工程化体系完整过一遍；后 7 章进入数据科学工具链，向量化思维和结构化数据处理是 AI 开发的日常刚需。

每章的结构

每章一个文件夹，固定三件套：

NN-章名/
  课件.md      # 讲义正文：概念 → 示例 → 练习
  demo.py      # 可运行演示代码
  answers/     # 练习参考答案（p1.py、p2.py…）

练习的使用方式：先自己写，卡住再看答案；答案只是一种解法，不是标准答案。所有示例与答案代码都带类型标注（前两章按内容进度除外）——这是课程坚持的工程习惯。

三条阅读路线

完整路线（零基础）：01 → 31 顺序读。对象模型部分（06-10）是全课程最硬的一段，慢一点没关系。

转语言路线（有其他语言经验）：快速过 01-05，精读 06-24——Python 的对象模型和并发模型与其他语言差异最大，也是面试和实战的高频区。

数据速成路线（急着用数据工具）：直接从 25 开始，25-31 连读；遇到 Python 语法障碍再回查前面对应章节。
