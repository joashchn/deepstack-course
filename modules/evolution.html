AI 应用技术演进

从 Transformer 到 Harness Engineering 的演进全景：LLM、提示词、微调、RAG、函数调用、MCP、Agent、多智能体、上下文工程、Skill、OpenClaw 与 Harness 十二个节点一次串讲，附论文与优质文档地图。

12 章Evolution

前六个模块是纵向深入：把 Python、Agent 原理、LangChain、LangGraph、后端、面试题一根根打透。这个模块是横向串讲——把「近年来 AI 应用技术」的十二个关键节点放在一条时间线上，讲清楚它们各自为什么出现、解决了什么问题、彼此如何接力，最后附上一张经过筛选的论文与优质文档地图。读完它，你脑海里那些散落在各模块的知识点会连成一张网：知道每一项技术在演进中的位置，比记住它的 API 更重要。

这个模块解决什么问题

课程前六个模块按「依赖关系」组织：先 Python、再原理、然后框架。这是学习效率最高的顺序，但代价是演进脉络被切碎了——你会在 Agent 核心第 11 章学 MCP，在 LangChain 第 6-8 章学 RAG，但很难回答这些问题：

  • MCP 是在什么背景下出现的？它解决了 Function Calling 的什么痛点？
  • RAG 和 Fine-tuning 是什么关系？什么时候该用哪一个？
  • Agent、Multi-Agent、Agent Skill 三者之间是什么递进关系？
  • 「提示词工程」和「上下文工程」为什么被放在一起讨论？谁取代了谁？
  • OpenClaw 和 Harness Engineering 是 2025-2026 年的新词，它们和前代技术是什么关系？

本模块用一条时间线回答这一切：2017 年 Transformer 提出 → 2022 年 ChatGPT 与 Agent 思想诞生 → 2023 年工具调用与 RAG 爆发 → 2024 年 MCP 与 Skill 标准化 → 2025-2026 年上下文工程、个人助手与约束工程。每个节点一章，十二章连成完整的演进叙事。

阅读路线

全景路线（推荐）：00 → 01 → 02 → … → 12 顺序阅读。十二章就是一条完整的演进时间线，每章约 15-20 分钟。

按需查阅（只对某个主题感兴趣）：直接跳到对应章节。每章都自包含：不依赖前面的章节也能读懂。

对照深读（学完某个模块后回来串一遍）：读完 Agent 核心任意一章，回到本模块找对应章节，看它在这条演进线上处于什么位置——你会发现很多「为什么这样设计」的答案其实写在演进历史里。

关于「更新」

这份串讲的底稿源自一份流传很广的技术串讲文档（Agent、Skill、OpenClaw、Harness……）。本模块保留其十二节点的骨架结构，但对每一节点做了三件事：补齐演进脉络（什么时候、因何出现）、展开核心概念（是什么、怎么工作）、更新到 2026 年的现状（今天的主流实践是什么）。文末的延伸阅读清单来自原文档的优质资源，并做了失效排查与补充。
