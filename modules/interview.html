12 章Interview

这是一套写给AI 应用开发工程师求职者的面试题库：覆盖 LLM 原理、RAG、Agent、LangGraph、LangChain 五大核心模块，系统设计、项目深挖、故障排查三类实战题，外加 Python 基础、FastAPI 后端、提示词工程、模型选型与降本四块通用功底——共 12 篇 81 题。全部题目对齐课程内容——你背的每一个答案，都能在课件里找到出处。

题库解决什么问题

转行求职者最怕的不是"不会"，而是"会一点但说不深"。面试官随手一个追问就见底：

  • 背了"RAG 是检索增强生成"，被问"检索不准你怎么优化"就卡壳；
  • 跑通了 Agent Demo，被问"死循环怎么防"答不上来；
  • 项目写上了简历，被问"为什么这么设计"只能重复功能描述。

这套题库用深挖式追问链解决这个问题：每道题模拟面试官的 3-4 层连续追问，每层都给出可直接背诵的深度回答，并标注考察意图与踩坑点。练完一道题，你就把这个知识点"说透"的能力练成了。

三条使用路线

求职冲刺路线（收到面试通知后，2-3 天）：02 → 03 → 07 优先。RAG 和 Agent 是 AI 应用岗最高频的两个模块；项目深挖题决定"你做过什么"的说服力。有余力再刷 09、10——Python 和 FastAPI 八股是转行者被"回归基础"考察时的重灾区。简历上还没有项目？先去 ../实战项目/ 把项目做出来，再回来刷 07 篇。

系统学习路线（正在上课或复习期）：01 → 02 → 03 → 04 → 05 → 11 → 06 → 12 → 08 顺序刷。题目难度与课件章节顺序对齐，可当复习提纲用；09、10 可穿插在等面试通知的空档期巩固。

模拟面试路线（临场训练）：只看追问不看答案，口头回答后再对照参考回答，标记说不满 1 分钟的题——那些就是你的薄弱点。

使用心法

  1. 先说结论，再展开。参考回答的第一句都是"一句话定义"，面试时先给结论再展开细节，是资深感的来源。
  2. 答案不是标准答案，是素材。把参考回答消化成自己的话，结合自己做过的项目改写，比逐字背诵效果强十倍。
  3. 卡在哪一层，回哪章课件。每题标注了对应课件，答不上第 3 层追问就去重读那一章。
  4. 追问链是真实比例。面试官问到你答不上的深度就会停止深挖——你能稳定答到第 3 层，就已经超过大多数竞争者。

频率与难度标记说明

  • 频率：极高（几乎必问）/ 高（常见）/ 中（区分度题，答好是加分项）
  • 难度：★ 越多越深。★★★ 及以下为基础必答题；★★★★ 是拉开差距的进阶题（其中频率"极高"的同样必答）。
