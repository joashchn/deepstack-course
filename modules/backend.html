模块 05 · 后端工程化

Python 框架指南

FastAPI 生态逐个零件拆开讲：路由、Pydantic、SQLAlchemy、依赖注入、JWT、SSE / WebSocket、测试与日志。

14 章Backend

这是一套 FastAPI 生态的 API 用法课程。不带你从零搭一个大工程，而是把每个零件拆开来讲清楚：它是什么、签名长什么样、最小示例怎么写、生产上常栽哪些坑。学完你能拿着手册对号入座，把任何一个 API 稳稳地用到自己的项目里。

课程结构

章 主题 一句话
01 FastAPI 入门与 ASGI 三大框架怎么选、Uvicorn 怎么跑、/docs 说明书怎么看
02 路由与请求响应 五个装饰器、路径/查询参数、请求体、response_model、APIRouter
03 Pydantic 数据校验与配置 Field 约束、校验器、BaseSettings 读 .env、DTO 三兄弟
04 SQLAlchemy 异步引擎与会话 create_async_engine、连接池、会话三种提交方式
05 ORM 建模 DeclarativeBase、外键、一对多/多对多、Mixin
06 SQL 表达式与数据操作 select/where/order_by、聚合分组、update/delete、防注入
07 Alembic 数据迁移 init 目录、autogenerate、手写 op、版本链管理
08 依赖注入 Depends 全家桶、yield 依赖、嵌套、测试换替身
09 统一异常处理 业务异常体系、错误码设计、exception_handler 注册
10 中间件 洋葱模型、计时、CORS、统一响应信封、注册顺序
11 认证与 JWT bcrypt 存密码、JWT 签发验票、get_current_user、/docs 的锁
12 pytest 测试 fixture、参数化、TestClient、异步测试、依赖覆盖
13 日志 loguru sink/轮转/上下文绑定、接管标准 logging、request_id
14 流式响应 SSE 与 WebSocket StreamingResponse、SSE 协议、WebSocket 广播、选型

章与章之间有衔接：04 章埋的 get_db，08 章正式展开，12 章拿它做依赖覆盖；09 章统一错误出口，10 章统一成功信封；10 章预告的 contextvars，13 章日志 request_id 兑现。建议按顺序过一遍第一遍，之后当手册查。

环境准备

# 需要 Python 3.12+ 和 uv
# 每章的 demo 都是单文件，装好依赖直接跑：
uv init          # 第一次进入某章目录时（或直接用下面的 add）
uv add fastapi "uvicorn[standard]"
uv run demo/demo_app.py

各章额外依赖在课件和 demo 文件头部注释里写明：

  • 04~07 章：uv add sqlalchemy aiosqlite（demo 用 SQLite 零环境可跑；课件主线讲 PostgreSQL，换库只改连接串一行）
  • 11 章：uv add pyjwt bcrypt python-multipart
  • 12 章：uv add --dev pytest pytest-asyncio httpx
  • 13 章：uv add loguru
  • 14 章：uv add sse-starlette websockets（可选，WebSocket 客户端验证用）

三条学习路线

快速上手（已经会别的框架，想一天入门）：01 → 02 → 03 → 08，之后需要什么查什么。

后端全流程（要接数据库做真实业务）：01 → 06 顺读，重点吃透 04 会话与 06 表达式，07 章 Alembic 跟着跑一遍迁移链。

打磨生产件（服务要上线了）：09 → 14 顺读。异常出口、响应信封、认证、测试、日志、流式，这一段是「能用」和「敢上线」的差距所在。

demo 的约定

  • 每章 demo/ 下一个或几个独立 .py 文件，单文件自足，不依赖其他章
  • 起服务的 demo 都是 uvicorn.run(app) 内嵌，直接 uv run demo/xxx.py，浏览器或 curl 按文件头注释里的地址验证
  • 数据库类 demo 用内存/文件 SQLite，跑完自动清理，重复运行不报错
  • 涉及 HTTP 的 demo 文件头都写好了 curl 验证清单，照着敲一遍比看十遍强

准备好了就从 01 · FastAPI 入门与 ASGI 开始。
