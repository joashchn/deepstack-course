模块 04 · 工作流编排

LangGraph 框架指南

围绕智能简历筛选系统，从一段脚本长成多 Agent、可恢复、可人工介入的生产级工作流。

17 章LangGraph

一本面向 Python 开发者的 LangGraph 系统性教程。全书围绕一个虚构但完整的业务——智能简历筛选系统——从一段三十行的脚本出发，一步步长成一个多 Agent、可恢复、可人工介入的生产级工作流。每一个核心机制的引入，都源于上一章暴露出来的真实工程问题。

适合谁读

  • 熟练使用 Python，能独立完成日常脚本与服务端开发
  • 已经会用 LangChain 调用模型、构造消息、绑定工具（本书不再铺垫这些内容）
  • 希望系统掌握 LangGraph，而不是只抄得出一个 ReAct 模板

环境约定

全书代码基于 langgraph 1.x，模型调用走 OpenAI 兼容接口（可对接 OpenAI、阿里云百炼、DeepSeek 等任意兼容服务商）。

uv init resume-screener && cd resume-screener
uv add "langgraph>=1.0,<2.0" "langchain-openai>=1.0" python-dotenv

在工程根目录准备 .env：

OPENAI_API_KEY=sk-xxxxxx
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen-plus

OPENAI_BASE_URL 按你所选服务商填写；不设置则默认连接 OpenAI 官方端点。 ChatOpenAI 会自动读取 OPENAI_API_KEY 与 OPENAI_BASE_URL，因此书中代码只需关心模型名。

各章 demo 均为自包含脚本，可直接保存为 .py 文件运行：

import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()
llm = ChatOpenAI(model=os.getenv("LLM_MODEL", "gpt-4o-mini"))

每章的结构

全书各章保持统一骨架，方便对照与回顾：

  1. 正文：从问题出发讲透原理，配精炼可运行的 demo
  2. 常见坑与排错：真实开发中高频翻车点
  3. 动手练习：2~3 道巩固题
  4. 本章速查：API 与概念的一页化总结

阅读建议

  • 严格按章节顺序读，后面的章节会复用前面搭建的图结构
  • 每章 demo 建议亲手跑一遍，改几个参数观察行为差异
  • 第 5、12、14 章是理解 LangGraph 运行时模型的三个关键节点，值得放慢速度
